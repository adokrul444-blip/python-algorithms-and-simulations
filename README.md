# Python Algorithms, OOP & Stochastic Simulations

A collection of three Python 3 software engineering projects focused on data analytics, object-oriented design patterns, and discrete-event Monte Carlo simulations.

## Projects

1. **[`marathon-data-analytics/`](./marathon-data-analytics)** — CSV telemetry parser, split-pace consistency analyzer, and automated ranking exporter for 42.195 km marathon datasets.
2. **[`ai-evaluation-lab-sim/`](./ai-evaluation-lab-sim)** — Multi-agent research lab simulation using OOP inheritance and the Strategy design pattern (`Chronological`, `ComplexProtocol`, `Efficient`) to schedule AI model evaluations.
3. **[`aircraft-boarding-simulation/`](./aircraft-boarding-simulation)** — Discrete-step 2D cabin grid simulation benchmarking 6 aircraft boarding algorithms (Steffen, WilMA, Back-to-Front, Front-to-Back, Aisle-to-Window, Random) under luggage and seat-interference constraints.
